# GeneratedGameData

This directory contains pre-converted runtime assets that are bundled directly into the iOS app.

- Put only converted/runtime-ready outputs here.
- Do not place raw PS3 dumps, encrypted fastfiles, keys, or private source folders here.
- The private importer writes validated outputs here so the app can load ready-to-use data without converting it again at launch.
- Generated content may be committed only when the repository owner has the right to distribute that derived content.
